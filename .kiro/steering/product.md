# Product Overview

This is a German AI Analysis Tool ("KI Analysetool") - a desktop application that allows users to analyze content from multiple sources using OpenAI's GPT models.

## Core Features

- **Multi-source content analysis**: Supports YouTube videos (via transcripts), websites (text extraction), and PDF documents
- **AI-powered analysis**: Uses OpenAI GPT-4o for content analysis with predefined prompts or custom user prompts
- **Analysis types**: Summarization, keyword extraction, sentiment analysis, topic recognition, and custom prompts
- **Export capabilities**: Results can be exported as PDF or copied to clipboard
- **German language interface**: All UI text and default prompts are in German

## Target Users

German-speaking users who need to quickly analyze and extract insights from various content sources using AI assistance.
